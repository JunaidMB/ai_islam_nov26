# AI & Islam Conference Talk

Authors: Junaid Butt, Shahel Khan

This repository contains the talk notes for the AI and Islam conference talk. The topic is on training modern language models, with a focus on how domain experts can input their knowledge into LLMs to change behaviour. The talk will be partitioned into the following sections:
1. General: Will cover theory of model training
2. Case Study: Will discuss a particular case study of how domain experts can align their frameworks with a sound model learning process
3. Future Directions and Community Entrypoints

## General

Sections to cover:

3. Post Training

    iii. Persona and Character Training
4. In Context Learning and Agents

The goal of this section is to provide basic theory and offer discussion about what domain experts interested in injecting Islamically acceptable response patterns can do at each stage.
